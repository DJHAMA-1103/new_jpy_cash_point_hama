# 지도·장소 검색 검토

2026-10-12. 지도 관련 구현·검토·재개 시 이 문서의 최신 기준을 먼저 읽는다. 전체 대화나 전체 코드를 다시 읽어 사용자가 같은 요구를 반복하게 하지 않는다.

## 최신 사용 방향 — 다음 구현의 필수 기준

- 승인 근거: 사용자가 지도 사용 방향을 Markdown으로 저장하고 이후 참고하도록 요청한 계획에 "Implement the plan.". 이번 승인은 기록 저장이며 지도 서비스 최종 채택 승인이 아니다.
- 등록 흐름: 지도 하나 → 매장명·약국명·슈퍼명·주소 검색 → 지점 목록(이름·주소) → 선택 및 지도 핀 확인 → 사용할 포인트·결제 앱 연결 → 등록.
- 기존 검정·흰색·노란색 디자인 유지. 위도·경도 직접 입력을 제거하고 좌표·기본 감지 반경은 내부 처리한다. 검색에 없는 장소는 지도에서 직접 지정할 수 있게 한다.
- 앱은 최초 등록과 추가·수정 때 주로 연다. 등록 이후에는 도착 알림 → 사용자 터치 → 우리 앱 경유 → 연결 앱 실행. 매달 재등록하거나 좌표 갱신 때문에 앱을 열도록 요구하지 않는다.
- Geoapify를 우선 검증 후보로 둔다. 출처 표시 등 조건을 충족하면 검색 결과의 장기 좌표 저장이 가능하므로 목적에 맞지만, 일본 매장 검색 품질은 추가 검증이 필요하다. 최종 채택·계정 발급·요금제 계약은 미확정이다.
- 검증할 구성: Geoapify 지도·검색 → 사용자가 선택한 좌표를 폰에 저장 → 휴대폰 위치 기능으로 도착 감지. 일본 지역·지도 주변 조건과 매장 검색 기능을 시험한다. 지역 제한만으로 검색 문제가 해결된다고 단정하지 않는다.
- Google Places 좌표에는 최대30일 캐시 조건이 있다. 별도 Geocoding API의 조건부 장기 보관 예외를 우리 앱에 적용할 수 있는지는 미확인이다. Google 결과를 Geoapify나 자체 서버에 복사해도 원본의 이용 제한이 없어지지 않는다. Google 검색과 장기 좌표 보관을 함께 충족하는 해결책은 아직 검증하지 않았다. [공식 조건 6.3.2·14.3](https://cloud.google.com/maps-platform/terms/maps-service-terms)
- 매장 검색 품질과 등록 후 도착 감지 정확도는 별개다. Google과 동일 조건의 API 비교를 하지 않았으므로 Geoapify가 Google보다 부정확하다고 확정하지 않는다. 좌표 보관이 가능하다는 사실만으로 iPhone 도착 감지·알림의 안정성을 검증했다고 주장하지 않는다.
- 현재 상태: 방향 기록 완료, 지도·검색 화면 교체는 아직 미구현. 아래 기존 조사와 실제 검색 근거를 보존하며 미검증 항목을 통과로 처리하지 않는다.

## 앞선 OSM 검토 결론

OSM은 지도 데이터 후보로 적합하다. 지도 표시 서버와 매장 검색 엔진은 별도 선정해야 한다. 무료 공용 서버를 무제한 운영 인프라로 취급하지 않는다. 최종 제공자·신규 계정·유료 계약은 아직 채택하지 않았다. 앱 코드 변경은 아직 없으며, 기존 좌표 입력 화면은 교체 대기다.

## 공식 조건

- OSM: ODbL 데이터. 출처·라이선스 표시 필요. 데이터 이용과 호스팅 비용을 구분한다. https://www.openstreetmap.org/copyright
- 공용 지도 타일: 가용성 보장 없음, 명확한 앱 식별과 캐시 필요, 대량 다운로드·오프라인 선취 금지. https://operations.osmfoundation.org/policies/tiles/
- 공용 Nominatim: 앱 전체 합계 최대 초당 1요청, 자동완성 금지, 운영자 요청 시 앱 업데이트 없이 제공자를 교체할 수 있어야 함. 이 공용 서버 정책은 자체 호스팅이나 다른 제공자의 서비스에 그대로 적용되는 것이 아님. https://operations.osmfoundation.org/policies/nominatim/
- Photon: OSM 기반 공개 검색 엔진. 입력 중 검색·오타 허용·위치 우선순위·영역 제한 지원. 데모 서버는 제한적인 사용만 허용하며 가용성을 보장하지 않음. 자체 운영 시 서버·업데이트·검색 튜닝 비용이 발생함. https://github.com/komoot/photon
- Geoapify: 일 3,000크레딧 무료, API10 월 USD59. 지도 타일·검색·결과 수별 크레딧 합산 필요. Places 결과 저장 허용 및 출처 표시 요구. https://www.geoapify.com/pricing/ · https://www.geoapify.com/places-api/
- LocationIQ: 무료 일 5,000요청, 초당2/분당60 제한. Maps Lite 월 USD45는 검색을 포함하는 상품으로 해석하면 안 됨. 영구 response-data 저장과 request-response 캐시 기간을 구분해야 함. 무료 캐시48시간을 모든 등록 좌표의48시간 삭제 의무로 단정하지 않음. https://locationiq.com/pricing · https://us1.locationiq.com/tos

## 다음 구현 조건

- OSM 지도 + 별도 일본 매장 검색 조합을 검토한다. Nominatim 공용 자동완성을 구현하지 않는다.
- 지점명이 검색되는 후보를 선정한 후 지도·검색 목록·핀 선택·앱 연결·원자적 저장을 통합한다. 공급자 키가 필요한 경우 발급 절차와 비용을 제시한다.
- 지도 제공자에 상관없이 좌표·감지 반경은 내부 처리한다. 기본 반경150m, 기존 장소 수정 시 반경 보존. 실제 저장 좌표와 도착 감지 전달 좌표를 함께 검사한다.
- 검색 결과 없음·통신 실패·위치 권한 거절·오래된 응답·중복 지점·등록 취소를 검증한다. 가짜 매장 결과를 정상 검색 결과로 표시하지 않는다.
